## 4. Generated output that lives inside tracked paths

`implementation/evidence/*.json` is tracked and is rewritten by every gate run
(`catalog`, `doctor`, `test-gpu`, `benchmark`, `fixtures`, `export_shaders`,
`verify`). These are small machine-readable results, so committing them is the
convention — but it means **a verification run always dirties the working tree.**
Expect 4–7 modified files after any full gate pass; that is normal and is not a
code change.

`implementation/` as a whole is 860 KB, `PLANNING/` 381 KB, `docs/` is now the
largest doc surface (architecture + performance-readiness + user guide + formats).

## 7. What is safe to delete to reclaim space

Nothing needs deleting for correctness, but by cost/benefit:

| Reclaimable | Size | Cost of deleting | Cost of regenerating |
|---|---|---|---|
| `target/` | 29 GB | next full build recompiles everything (~15–25 min cold) | `cargo build --workspace` |
| `target_link/` | 1.4 GB | loses the prebuilt `abl_link.lib`, so feature `link` needs a CMake rerun | cmake + build, documented in `implementation/STATE.json` |
| `test_out/ smoke/ rec_out/ media_out/ sdf_out/ txt_out/` | 224 MB | loses nothing reproducible | the same commands that made them |
| `fixtures/` | 18 MB | CI regenerates it | `cargo run -q -p xtask -- fixtures` |
| `_upstream/` | 101 MB | breaks shim rebuilds until re-cloned | re-clone official SDKs |
| `.git` history | ~900 MB of pack is dead artifacts | **do not touch without being asked** — rewriting history is the user's call | n/a |
